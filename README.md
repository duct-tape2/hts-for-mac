# Moa Desk

**맥에서 국내·미국주식을 한 화면에 모아 보는 조회·분석 작업공간.**

촘촘한 시세 표, 도킹 창, 종목 연동과 여러 작업공간을 제공합니다. 키움 REST API를 사용하는 개인용 앱이며 키움증권 공식 HTS가 아닙니다. **주문·정정·취소·자동매매·환전·이체·개인 계좌 조회는 없습니다.**

## 주요 기능

- 국내·미국 종목 검색, 현재가·호가·시장 체결, 관심종목 그룹과 국내 순위·수급.
- 기본13종 화면,4개 작업공간,다중 차트,분리 창,종목 연동/고정,배치 저장·복원.
- Lightweight Charts 기반 분·일·주·월·년 차트,지표,저장 작도,최대4종목 상대수익률 비교.
- 프로그램·기관·외국인·ETF·테마 분석,저장 조건검색,관심그룹 로컬 필터,알림,관찰 기록·계산기·개인 분석 백업.
- Keychain 키 저장,접속 토큰 자동 갱신,사용자가 입력한 API 등록 만료일의7일 전 재발급 안내.

## 설치와 실행

macOS, Git, [uv](https://docs.astral.sh/uv/), Node.js22.13 이상인22.x 또는24.x/26 이상과 npm이 필요합니다. Python3.13은 uv가 준비합니다.

```bash
git clone https://github.com/duct-tape2/moa-desk.git
cd moa-desk
./scripts/setup.sh
./dev.sh
```

[http://127.0.0.1:3010](http://127.0.0.1:3010)을 엽니다. 첫 실행은 **합성 테스트 데이터(fixture)** 이며 API 키가 필요 없습니다. 새 브라우저의 기본 화면은13종 순위 배치입니다. 기존 저장 배치는 보존됩니다.

실제 시세를 보려면 테스트 실행을 Ctrl+C로 종료하고 다음을 실행합니다.

```bash
npm --prefix frontend run build
python3 scripts/run_local.py --environment real
```

화면의 **API 연결 설정**에서 본인의 키움 App Key·App Secret과 발급 화면의 등록 만료일을 입력합니다. 만료일은 사용자마다 직접 입력하며 특정 날짜로 고정하지 않습니다. 접속 토큰은 자동 갱신하지만 API 등록 자체가 만료되면 본인이 재발급한 키와 새 날짜를 입력해야 합니다. 서버와 브라우저 화면은 실행기가 함께 관리하며 Ctrl+C로 종료합니다.

실행 중 코드 변경을 반영할 때는 다른 터미널에서 `python3 scripts/run_local.py --reload`를 사용합니다. 개발 모드는 `./dev.sh --environment real`입니다. 포트3010/8010이 사용 중이면 다른 프로세스를 강제 종료하지 않고 실행을 중단합니다.

키와 개인 설정을 Git에 올리지 마세요. `.env`는 자동으로 읽지 않습니다. 로컬127.0.0.1 전용이며 인터넷 서버로 열어 사용하는 구조가 아닙니다.

## 화면 사용

상단 화면번호·이름으로 기능을 열고, 같은 연동 번호의 창끼리 종목을 공유합니다. 종목 고정은 그 창만 유지합니다. ＋는 창 복제, ↗는 별도 창 분리입니다. 탭·경계선을 끌어 배치를 바꾸고 작업공간 메뉴에서 내보내기/가져오기를 사용합니다.

`Home`: 화면검색 · `Ctrl+1~4`: 작업공간 전환 · 관심종목 방향키: 종목 이동 · 차트 방향키/+/−/*: 이동·확대·전체 보기.

다른 Mac으로 옮기는 방법은 [설치·이전 안내](docs/hts/MAC-MOVE.md)를 참고하세요. 배치·메모·작도는 사용자가 직접 내보내며 API 키는 새 Mac에서 다시 등록합니다.

## 데이터 범위와 알려진 제한

실시간·스냅샷·미수신·오류와 일부 조회를 구분합니다. 실제 조회가 실패해도 합성 가격으로 대체하지 않습니다. 원시 거래시각의 날짜·시간대가 확인되지 않으면 거래소 봉으로 추정하지 않습니다. 비교차트는 환율을 적용한 투자수익률이 아니라 수신 종가의 상대변화입니다.

국내 일반 종목 연결은 KRX 기준입니다. 지원되는 순위·수급 API에 한해 NXT/통합 필터를 제공합니다. 조건검색은 키움에 이미 저장된 조건을 조회하며, 앱 자체 필터는 관심종목의 확보된 데이터만 평가합니다. 알림은 지원 브라우저와 열린 앱·수신 연결이 있어야 작동합니다.

공시·재무는 별도 공급원을 사용합니다. DART는 본인 OpenDART 키, SEC는 실제 연락처가 포함된 User-Agent를 설정해야 합니다. 미설정이면 안내를 표시하며 키움 시세는 계속 사용할 수 있습니다. 뉴스는 무료 RSS 제목·제공 요약·원문 링크 범위입니다.

현재 확인된 키움 거절: 시간외 단일가 호가/순위(ka10087·ka10098,1504),미국 관심종목 통합 조회(usa20922,1517). 해당 화면은 오류를 명시합니다. 다른 조회 기능의 성공을 이 세 기능의 성공으로 해석하지 않습니다.

이 릴리스는 소스 설치용 사전 출시 버전입니다. 서명된 독립 macOS 앱/Tauri 패키지,영웅문 전체 기능 동일성,다른 Mac 물리 설치,6시간 부하·장중 같은 시점 대조를 완료했다고 주장하지 않습니다. 세부 검증 결과는 릴리스 노트를 확인하세요.
