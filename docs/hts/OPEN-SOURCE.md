# 사용한 공개 프로젝트와 라이선스

- 기존 앱: https://github.com/chicago007/kiwoom_mac_trading, 기존 로컬 커밋 6b5f49ab. 화면·React/Next·FastAPI 기반을 유지하며 원저작자의 수정본 공개 배포 허락을 받았다는 사용자 확인에 따라 확장본을 공개한다. 원본 전체에 별도 공개 라이선스를 추정하여 부여하지 않는다.
- 차트: https://github.com/tradingview/lightweight-charts, npm 5.2.1, Apache-2.0. 라이브러리가 시세를 제공하는 것은 아니다. 키움 응답 또는 명시된 fixture를 입력한다. 차트에 TradingView 출처 링크를 표시한다.
- 패널 배치: https://github.com/caplin/FlexLayout, npm flexlayout-react 0.11.1, MIT. 패널 이동·분할·최대화·내부 분리 창·JSON 저장에 사용한다.
