# Moa Desk 검증 범위

이 버전은 주문 기능이 없는 로컬 브라우저 기반 소스 프리릴리스다. 서명된 macOS 앱이나 영웅문 전체 복제 완제품이 아니다.

## 수정한 검수 항목

GPT Pro는 실제 소스·테스트·앱 화면을 검토하고 격리 재현으로 REVISE를 제시했다. Antigravity Argon(gemini-4-argon-high)도 실제 소스를 정적으로 검토해 REVISE를 제시했다. 두 결과를 그대로 통과로 보고하지 않고 아래 수정과 회귀검증에 사용했다.

- 설치에 필요한 설정·정적 분리창·실행 파일을 배포 목록에 포함. 새 Git 이력에는 런타임 데이터와 개인 화면을 포함하지 않음.
- 국내·미국 관심목록 실패·누락·잘못된 거래소 응답에서 기존 그룹 보존. 정상 빈목록만 허용.
- 알림 무변경 평가 루프 중지, 숨겨진 창 감시권 반납과 보이는 창 인계.
- 조건검색 소켓 재연결 시 취소 상태 반영, 닫힘·시장/탭 전환 중 늦은 등록 응답 해제. 등록마다 별도 식별자를 사용해 이전 창이 새 등록을 해제하지 않도록 제한.
- SEC 지표별 최신 자료를 균형 있게 보존, SEC/DART 상한 적용 시 일부 수신과 개수 표시. SEC 연락처 ASCII 검증.
- 외부 웹페이지의 로컬 조회 유발 차단, KOSDAQ 동적 업종 시장 선택 및 전면 공급자 오류 상태 수정.
- 저장된 키가 있는 첫 실행과 일시적 토큰 오류 안내 수정. 새 실행기의 터미널 종료와 명시적 reload 신호 분리, 구버전 reload 호환.
- 분리 창 종료 이벤트가 생략되어도 창 닫힘을 확인해 같은 패널 설정의 내부 창으로 복구.

- 첫 실시간 구독 중 SDK가 pandas를 지연 import하며 처리 스레드를 막던 경로를 초기화 단계로 이동. 공식 SDK 패킷 생성기를 그대로 사용하며 대기시간 기준은 완화하지 않음.

## 검증 범위

동일 Mac의 빈 디렉터리에서 공개 패키지 잠금 파일을 이용해 설치·타입 검사·프로덕션 빌드·합성 데이터 실행과 API 스모크를 통과했다. 실제 다른 Mac 물리 설치는 수행하지 않았다. 새 Python 3.13 환경의 전체 Python 테스트 358개, 프런트엔드 테스트 292개, 타입 검사와 프로덕션 빌드가 통과했다. 실행용 npm 의존성 취약점은 0건이다. GPT Pro는 조건검색 소유권·국내 관심목록 보존·분리 창 복구 집중 재검수를 PASS로 판정했고, Argon은 실행기·인증 안내·조건검색 UI·로컬 요청 경계 재검수를 PASS로 판정했다. 전체 Windows HTS 동등성 인증으로 해석하지 않는다. GitHub CI와 마지막 추가 변경 검수 결과는 릴리스 본문에 기록한다.

기존 실서버 조회 기록 85건: 데이터 79건, 정상 빈값 3건, 공급자 거절 3건. 전체 응답 형식 검사는 통과했다. 이는 공식 HTS와 같은 시각의 가격·시간·단위 전수 대조를 뜻하지 않는다.

## 남은 제한

키움 시간외 단일가 호가·순위(ka10087/ka10098:1504)와 미국 관심종목 통합 조회(usa20922:1517)는 공급자 거절을 표시한다. 성공으로 표시하거나 합성 가격으로 대체하지 않는다.

실제 저장 조건 KR/US 목록이 각각 0건이므로 실계정 편입·이탈은 검증하지 못했다. 6시간 부하, 잠자기 복귀, 다른 Mac 물리 설치, 13화면 전수 픽셀 비교, 장중 공식 HTS 동시 대조는 완료로 주장하지 않는다. 앱이 닫히거나 모든 창이 숨겨진 동안의 백그라운드 알림은 보장하지 않는다.

## GitHub 새 설치 실사용 검증 — 2026-10-26

공개 RC1을 새 디렉터리에 clone하고 기존 가상환경·빌드·시세 캐시 없이 설치했다. 설치·타입 검사·프로덕션 빌드·fixture API smoke를 통과했다. 같은 Mac의 Keychain에 등록된 키를 앱이 직접 사용해 실서버 연결과 재실행을 확인했다. 새 기기에 키를 처음 입력하는 수동 작업 자체는 재현하지 않았다.

삼성전자·SK하이닉스·AAPL의 검색, 현재가·10호가, 일봉·분봉이 실제 공급자 응답을 반환했다. 30초 다중 종목 스트림에서 세 종목 모두 실시간 상태와 호가 갱신을 관측했다. 국내·미국 차트의 통화·종목 분리, 4차트 표시, API 등록일·접속 토큰 만료일 구분을 브라우저에서 확인했다.

89개 분석 기능의 기본 조회는 76개 snapshot, 4개 missing, 4개 별도 설정 필요, 2개 입력 오류, 2개 공급자 오류, 1개 필수 관심목록 미입력으로 분류됐다. 테마코드 550 입력 후 구성종목 3행을 확인했다. 미국 관심목록을 명시하면 usa20922는 기존 1517 오류를 반환했다. 저장 조건은 KR/US 모두 빈 목록이며 US는 첫 요청 시간 초과 후 재조회가 성공했다.

RC2는 필수 조회조건 안내 누락을 수정한다. 테마코드·ETF 대상지수코드·미국 관심목록 입력 전 자동 조회를 막고 필요한 입력을 표시한다. 현재 공급자 종목 목록에서 확인되지 않은 BRK.B의 고정 빠른선택만 제거하며, 실제 검색 결과의 점이 포함된 종목 지원은 유지한다.

**키움 키만으로 모든 자료가 열리는 것은 아니다.** OpenDART 2개 기능은 별도 DART 키, SEC 2개 기능은 실제 연락처가 포함된 User-Agent가 필요하다. ETF 수익률은 공급자의 대상지수코드 추가 입력이 필요하며 유효 코드의 실서버 결과는 미검증이다. 실제 토큰 만료까지 기다리는 대신 만료·401·동시 갱신 관련 모의 테스트 32개를 실행했다.
